- **관리자 커리큘럼 관리: 출시 전 배포 작업 필수 🔴** — v3.11 Edge Function
  미배포로 관리자 반/유닛/단어 CRUD가 프로덕션에서 404로 깨져 있을 가능성이
  높다(§4-A). 이건 코드 버그가 아니라 **배포 순서 미완**이며, 운영자가
  런북(`docs/audit/2026-07-26-v3_11-1hour-runbook.md`)대로 배포하면 복구된다.
- **보안: 출시 전 락다운 배포 필수 🔴** — v3.11(classes/units/words) +
  v3.12(daily_assignments, 신규 발견) 미적용. anon 쓰기가 열려 있다.

**결론: "학생 베타"는 지금도 안전하게 시작 가능하나, 관리자가 커리큘럼/숙제를
편집하려면 v3.11 배포가 선행돼야 한다. 즉 실질적 베타 게이트 = v3.11 배포 +
v3.12 락다운.**

## 4. 알려진 한계 (Known Limitations)

### A. 🔴 v3.11 미배포 → 관리자 커리큘럼 쓰기 프로덕션 장애 가능성
프론트는 pin(truthy)으로 admin-content-write(미배포, 404)에 라우팅 →
반/유닛/단어 생성·수정·삭제·설정 저장이 "관리자 쓰기 서비스 응답 실패"로
throw. **배포 순서 미완이 원인, 코드 버그 아님.** 런북대로 배포 시 해소.
(`docs/SECURITY_AUDIT_V311.md` §3)

### B. 🔴 daily_assignments 무인가 쓰기(신규 발견, CRITICAL)
공개 anon key로 인증 없이 임의 반/날짜 숙제 단어를 덮어쓸 수 있다.
v3.11과 같은 취약점 클래스인데 누락됨. 비활성 SQL(`supabase_v3_12_...sql`,
미적용) + 코드 배선 계획 문서화 완료. (`docs/SECURITY_AUDIT_V311.md` §4)

### C. 🟡 미니게임 "올클리어 보너스" 미지급 (표시는 이번에 정정)
`PERFECT_BONUS=10`이 상수/화면엔 있으나 `onGrantReward`로 지급된 적 없음.
이번에 **표시를 실제 지급값에 맞춰 정정**(과다 약속 제거). 남은 결정:
이 보너스를 실제로 **지급**할지(제품 의도였다면 result 진입 시 세션
스코프 dedupKey로 1회 grant 추가) — 경제 변경이라 운영자 판단 필요.

### D. 🟡 발음 별 dedup의 라운드 스코프 의미 불일치
`grantReward` dedup 로그(`starGrantLog`)가 `round`에 저장돼 4/4 완료마다
리셋된다. 발음 별 dedupKey(`pronunciation:wordId:today`)는 "하루 1회"를
암시하지만 실제로는 "라운드당 1회"라, 같은 단어를 새 라운드에서 다시
발음하면 별을 또 받을 수 있다. 다만 코드 주석은 "별은 라운드마다 반복
지급"을 의도로 명시하기도 해 **의도 자체가 코드 내에서 상충**한다.
"고치면" 학생이 받는 별이 줄어드는 경제 변경이라 자율 세션에서 변경하지
않음 — 제품 의도 확정 후 결정 권장. 현재 피해: 소량 별 과지급(크래시·
데이터손상 아님).

### E. 🟢 기프트 애니메이션 스킵(LOW, 저빈도)
연속 라운드에서 같은 스티커 id가 연달아 나오면 `GiftReveal` key 충돌로
상자 열림 애니메이션이 생략될 수 있음. 순수 시각 효과, 데이터 영향 없음.
수정 시 key에 고유 인덱스 추가(1줄). 이번엔 안정성 우선으로 문서화만.

### F. 🟢 빌드 chunk-size 경고(기존)
`index`/`AdminScreen` 청크 >500KB 경고. 기능 영향 없음, 기존부터 존재.
코드 스플리팅은 별도 성능 작업(범위 밖).

## 5. 출시 전 필요한 수동 테스트 (Manual Tests Needed)

Edge Function/배포 경로는 하네스로 검증 불가 → 운영자가 프로덕션에서
직접 확인. `docs/audit/2026-07-26-v3_11-1hour-runbook.md` §4·§5가 상세.

**관리자(배포 후 필수)**: 반 생성 / 반 이름변경 / 반 삭제(테스트반) /
유닛 추가 / 단어 엑셀 업로드 / 단어 PDF 업로드 / 단어 개별수정 / 추가
정답 인정 / 쓰기시험 설정 / 게임화 설정 / **숙제 배정 저장** 각 1회.
→ 전부 정상 저장돼야 v3.11(+v3.12) 배선이 라이브에서 맞다는 뜻.

**학생(회귀 확인)**: 로그인 / 유닛 전환 / 단어 학습·발음 / 예문 / 녹음 /
퀴즈 / 쓰기시험 / 4·4 미션→기프트 / 캘린더 / 다이어리 스티커.

**모바일 브라우저**: iOS Safari·Android Chrome에서 로그인 유지(세션),
오디오 재생, 녹음, 새로고침 후 진행도 복구, 백그라운드 복귀 재동기화.

   anon 쓰기가 열려 있음(2026-07-24부터 지속, 신규 악화는 아님).

   데이터 섞임 — 베타(단일 학원)엔 무관. `docs/SAAS_READINESS_REVIEW.md`.
