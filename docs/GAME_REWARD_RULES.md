| 자원 | 채택 | 역할 | 비고 |
|---|---|---|---|
| **Star(별)** | ✅ 기존 유지 | 세션/학습 단위의 즉시 보상. 기존 `student_progress.total_stars`·`student_daily_progress.stars_earned`와 호환 — 의미 재정의 없음 | 기존 데이터 무변경 |

| **Level** | ✅ 기존 Paul Rank 위에 매핑 | 장기 성장 | 신규 레벨 체계를 따로 만들지 않고 Rank 단계와 통합 |

## 1. Reward Table (행동 → 보상)

원칙: **보상은 학습 행동 완료 후에만**, 세션당 상한 존재, 재시도 정답도
보상하되 첫 시도보다 작게(고의 오답 파밍 차단 §7).

| 행동 | Star | XP | Ticket | 조건/상한 |
|---|---|---|---|---|
| 단어 1개 학습 완료(카드 넘김) | 0 | 0 | 0 | 보상 없음 — 넘기기 파밍 차단 |
| 퀴즈 정답(첫 시도) | 1 | 1 | 0 | 세션 내 단어당 1회 |
| 퀴즈 정답(재시도 성공) | 0 | 1 | 0 | 단어당 1일 1회 |
| 5연속 정답 콤보 | +1 | +1 | 0 | 세션당 최대 3회 |
| 쓰기(철자) 정답(첫 시도) | 1 | 2 | 0 | 철자가 더 어려우므로 XP 가중 |
| 발음 연습 1단어 완료 | 0 | 1 | 0 | 단어당 1일 1회 |
| 모르는 단어(unknown) 재학습 → 정답 | 1 | **3** | 0 | **최고 단가** — 복습이 핵심 목표. 단어당 1일 1회 |
| 카테고리(학습 모드 1종) 완료 | 1 | 2 | 0 | 카테고리당 1일 1회 |
| **오늘의 미션 전체 완료** | 3 | 10 | 1 | 1일 1회 |
| 주간 챌린지 완료 | 5 | 30 | 3 | 주 1회 |
| Streak 마일스톤(§4) | 0 | 표 참조 | 표 참조 | 마일스톤당 1회 |
| 출석만(학습 없이 접속) | 0 | 0 | 0 | 출석 보상 없음(운영자 원칙) |

## 2. 오늘의 미션 (Daily Mission)

구성(기본 4칸 — 학생별 숙제 배정과 연동, 배정 없으면 기본 세트):
1. 단어 N개 학습 (N = 오늘 배정 단어 수, 배정 없으면 유닛 기준 20)
2. 뜻 퀴즈 완료 (categories_completed 기준)
3. 철자 쓰기 완료
4. 틀린/모르는 단어 다시 공부 (unknown 재학습 ≥ 1, unknown 0개면 자동 달성 표시 "오늘은 없음!")

판정 데이터: `student_daily_progress`(당일 행) + `word_status` — **전부 기존
기록에서 파생 계산**(신규 쓰기 없음, P0). 완료 보상 지급은 서버 멱등 기록
필요(P1 — §8 원장).

## 3. XP → Level 곡선

기존 Paul Rank 단계와 통합(별도 레벨 신설 금지). 레벨 n 도달 누적 XP:

`XP(n) = 25 × n × (n − 1)` (n ≥ 1)

| Level | 누적 XP | 증분 | 호칭(초등/중등 공용 톤) |
|---|---|---|---|
| 1 | 0 | — | Starter |
| 2 | 50 | 50 | Word Walker |
| 3 | 150 | 100 | Word Runner |
| 4 | 300 | 150 | Word Hunter |
| 5 | 500 | 200 | Vocab Ranger |
| 6 | 750 | 250 | Sentence Builder |
| 7 | 1,050 | 300 | Quiz Breaker |
| 8 | 1,400 | 350 | Spelling Ace |
| 9 | 1,800 | 400 | Word Expert |
| 10 | 2,250 | 450 | Word Master |
| 11+ | +500/lv 고정 | 500 | Master ★n (프레스티지 별) |

설계 의도: 초반 3레벨은 2~3일 내 도달(goal-gradient), 이후 선형 증가로
"다음 레벨까지 항상 계산 가능"(예측 가능성 — 초등학생 이해 용이).

## 4. Streak

- **인정 기준**: "최소 학습 기준 완료일" = 당일 `student_daily_progress`에
  `categories_completed ≥ 1` **또는** 퀴즈 정답 ≥ 10. 단순 접속은 불인정.
- **Freeze(보호)**: 주(월~일) 1회 자동 — 하루 빠져도 streak 유지, 화면에
  "🧊 보호 사용됨" 표시. 이월 불가. (초등 좌절 방지 — 전부 잃는 구조 금지)
- **장기 보존**: 최고 기록(best streak)은 영구 표시 — 끊겨도 자산이 남는다.
- 마일스톤 보상: 3일 +5XP / 7일 +15XP+Ticket 1 / 14일 +30XP+Ticket 2 /
  30일 +60XP+Ticket 3+전용 Badge / 이후 30일마다 반복.
- 계산은 `student_daily_progress`의 날짜 나열에서 파생(P0 표시는 신규 쓰기
  0). 마일스톤 "지급"은 서버 멱등 필요(P1).

## 6. Weekly Challenge (주간)

기간: 월 00:00 ~ 일 23:59(KST, 운영자 지정 기간 오버라이드 가능 — 기존
Seasonal Progression의 시즌 경계 관례 재사용). 기본 목표(운영자 편집 가능):
- 단어 100개 학습 / 오답·unknown 30개 정답 전환 / 쓰기 5세션 / 학습일 5일
완료 보상: §1 표. 부분 달성도 진행 바로 표시(all-or-nothing 금지).

## 7. Anti-Farming Rules (필수 구현)

1. **단어당 일일 보상 캡**: 같은 단어의 같은 행동은 하루 1회만 보상
   (재시도 XP 포함). 키: (student_id, word_id, action, date).
2. **고의 오답 차단**: 재시도 정답 XP(1)는 첫 시도 정답 XP(1)+콤보 기대값
   보다 항상 낮거나 같게 유지 — 일부러 틀릴 유인 제거. 동일 단어 오답→정답
   보상은 1일 1회.
3. **세션 상한**: 콤보 보너스 세션당 3회, 세션 완료 보상 카테고리당 1일 1회.
4. **멱등 지급**: 모든 지급은 원장 append + idempotency key(기존 XP/Ticket
   원장의 중복 지급 방지 패턴 재사용). 새로고침/뒤로가기/재전송/다중 탭에서
   같은 키 재요청 시 무시.
5. **클라이언트 불신**: 미션/뱃지/streak "판정"은 파생 계산이라 클라이언트가
   해도 되지만, "지급"은 서버(API)가 기존 기록을 재검증 후 원장 기록(P1).
   localStorage 조작은 표시만 바꿀 뿐 지급에 영향 없음.
6. **이상 감지(관리자)**: 일일 XP > 200 또는 동일 action 반복 > 50회 학생을
   관리자 화면에 플래그(§8 감사 뷰).

## 8. 지급 원장(설계 — DB 변경 필요, 실행 금지)

기존 XP/Ticket 원장 테이블을 그대로 쓰되, 미션/뱃지/streak 지급의 멱등 키
관례를 통일: `reason` = `mission:{date}` / `badge:{code}` / `streak:{n}:{date}`.
신규 테이블이 필요하면 additive로만(`reward_events` — student_id, kind,
key UNIQUE, amount, created_at). SQL은 설계만 — 운영자 승인 후 실행.

## 9. Celebration 계층 (지속시간/스킵)

| 트리거 | 강도 | 지속 | 스킵 |
|---|---|---|---|
| 정답 1개 | 체크+별 팝(기존) | ≤400ms | 불필요(비차단) |
| 5콤보 | Paul 리액션 소(기존 자산) | ≤800ms | 탭으로 즉시 |
| 카테고리/세션 완료 | 별 획득 연출(기존) | ≤1.5s | 탭 |
| 오늘의 미션 완료 | 풀스크린 1회 | ≤2.5s | 탭 |
| 레벨업/골드 배지 | 최대 연출+Paul | ≤3s | 탭 |

연출은 CSS transform/opacity만(저가 기기), 동시 1개만 큐잉.

## 10. 연령 모드 표현 강도

데이터/규칙은 단일. 표시 프로파일만 3종(반 단위 설정, 기본 elementary):
- elementary: 캐릭터/스티커/큰 연출
- middle: 레벨/업적/streak 중심, 연출 1단계 축소
- high: progress/mastery/Personal Best 중심, 연출 최소(정답 피드백+주간 요약)
