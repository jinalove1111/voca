# Town V1 진입 카드 온디바이스 진단 (2026-09-12)

_근거: Kinney 실기기(Samsung Internet)에서 관리자가 "🎯 기능"에서
`paulTownV1`을 체크했는데도 학생 화면에 "🏘 내 마을 — Welcome to Paul
Town / 들어가기" 카드가 계속 안 보인 사고. 근본 원인(페이지 인스턴스당
한 번만 로드되던 플래그 메모리 캐시)은 PR #46로 수정·배포됐다(크로스탭/
포그라운드 재조회 + 저장 read-back 검증, `src/config/features.js`의
2026-09-12 헤더 주석). 그런데도 같은 기기에서 여전히 재현된다면 남은
가능성은 두 가지뿐이다 — (a) 이 브라우저가 애초에 저장을 거부/무시했다,
(b) 관리자가 토글한 저장소와 학생이 읽는 저장소가 서로 다른 컨텍스트
(오리진/프로필/모드)다. 둘 다 원격에서는 재현 불가능한 "그 기기에서만
확인 가능한 사실"이라, 운영자에게 "다시 한번 꺼봤다 켜보세요"를 요청하는
대신 관리자 화면이 그 진실을 화면에 그대로 보여주도록
`src/components/FeatureManagementPanel.jsx`에 온디바이스 진단 라인을
추가했다(이 문서가 그 사용법)._

## 1) 어디서 보는가

관리자 → ⚙️ 관리자 PIN 로그인 → **🎯 기능** 탭 → **애착 시스템
(Attachment & Growth)** 카테고리를 펼친다.

- 탭 맨 위: `이 화면의 주소: <origin><path> · 저장소: OK|차단됨`
- `paulTownV1` 체크박스 바로 아래(라벨 안): `저장됨: true|false|unset|read-error`
  - 초록 글자 = `true`(정상 저장됨)
  - 회색 글자 = `false` 또는 `unset`(체크박스도 꺼져 있어 일치)
  - 빨간 글자 + " · 메모리와 불일치" = 체크박스는 켜져 있는데 저장소에는
    반영되지 않음(아래 해석표의 "저장소 차단/실패" 케이스)

이 두 줄은 매 렌더링마다 `localStorage`를 직접 다시 읽어서 계산한다 —
화면에 켜진 것처럼 보이는 메모리 상태가 아니라 "이 브라우저의 이 순간
실제 저장소 내용"이다.

## 2) 해석표

| 관찰 | 의미 | 다음 행동 |
|---|---|---|
| `저장됨: true` (초록) + 학생 화면에 카드 있음 | 정상 | 없음 |
| `저장됨: true` (초록) + 학생 화면에 카드 없음 | 관리자 세션과 학생 세션이 **서로 다른 저장소 컨텍스트**를 쓰고 있다(다른 origin/배포 URL, 다른 브라우저 프로필, 관리자는 일반 모드인데 학생은 시크릿/게스트 모드 등) | 학생이 실제로 쓰는 그 창에서 직접 관리자로 로그인해 같은 화면(🎯 기능 → paulTownV1)을 열고 `저장됨:`/주소 줄을 확인. 주소 줄의 origin이 관리자 기기와 다르면 그게 원인. |
| 체크박스 켜짐 + `저장됨: false` 또는 `unset`(빨강 + "메모리와 불일치") | 저장 자체가 막혔거나(프라이빗 모드/용량 초과) 조용히 실패했다 | 상단 `저장소:` 줄 확인 → `차단됨`이면 브라우저가 이 사이트의 저장 기능을 막고 있는 것(프라이빗/시크릿 모드 종료, 사이트 데이터 차단 설정 해제, 다른 브라우저로 재시도) |
| `저장소: 차단됨` | 이 브라우저가 `localStorage` 쓰기 자체를 거부(프라이빗 모드, 일부 임베디드 웹뷰, 사이트 데이터 차단 설정) | 브라우저 설정/모드를 바꾸거나 다른 브라우저(Chrome/Samsung Internet 일반 모드 등)로 재시도 |

## 3) 엔지니어링에 보고할 때

위 표로 원인을 좁힌 뒤에도 해결이 안 되면, **학생이 실제로 쓰는 그 창**
기준으로 다음을 캡처해서 보낸다:

1. 그 창에서 관리자로 로그인해 연 "🎯 기능 → 애착 시스템" 화면의
   스크린샷(상단 주소/저장소 줄 + `paulTownV1` 저장됨 줄이 모두 보이게).
2. 학생 화면(대시보드 → Paul Town) 스크린샷.
3. 브라우저 이름/버전, 일반 모드인지 시크릿/게스트 모드인지.

토글을 다시 하라는 지시는 이 문서의 범위가 아니다 — 위 캡처가 "왜 다시
켜도 안 되는지"를 판별하는 데 필요한 최소 증거다.
