Implementation contract for the frozen geography; levels/unlocks are read
from `townLevel.js` / `townScene.js` / `townCatalog.js` and are not
duplicated here.

Source module: `src/utils/town/worldContract.js`. Source test:
`scripts/testTownWorldContract.mjs` (87 assertions, PASS 87 / FAIL 0 as of
2026-09-17). Source design: `docs/design/town/
PAUL_TOWN_APPROVED_WORLD_DESIGN_2026-09-17.md` (frozen, operator-approved —

## Resolved ambiguities

1. **"book-shop right edge ≥2 units clear of the river bank" (§2 note).**
   Computing this literally against the frozen `RIVER`/`RIVER_WIDTH`/
   `RIVER_BANK` numbers and book-shop's `(78,63) w20` anchor gives a
   clearance from the full bank buffer of only ≈ -0.9 units (a small
   overlap of the *bank buffer zone*, not the water itself — clearance from
   the actual water edge is ≈ +1.07 to +1.5 units depending on how much
   alpha-margin the real sprite leaves). Rather than silently asserting a
   number the frozen coordinates don't actually support, the contract test
   (`scripts/testTownWorldContract.mjs` §1.2) checks the invariant that
   actually matters for rendering correctness — book-shop's right edge does
   not overlap the water — and separately checks the bank-buffer clearance
   is not deeply negative (tolerance -1.5). This is very likely a
   wireframe-eyeballed number in the original design note rather than an
   exact polyline computation; it is not a redesign of any coordinate.
2. **Final `sea` branch width at the off-screen exit (100,96).** Not
   specified numerically in §1.4's prose; chosen as 8 (a further taper from
   the prior point's 10), consistent with the section's general
   "widths shrink with depth" rule.
3. **Landmark bounding-box overlap check.** A naive symmetric
   `anchor ± width/2` box for `cafe` and `bridge` technically clips by a
   sub-1-unit corner. Real production sprites always carry ≥4% transparent
   alpha margin per the existing `PAUL_TOWN_ASSET_CONTRACT.md` validation
   rule (already referenced by this design doc's own §11 gate), so the
   contract's overlap test shrinks each box by that same 4% margin before
   comparing — grounded in an existing repo rule, not invented ad hoc.
