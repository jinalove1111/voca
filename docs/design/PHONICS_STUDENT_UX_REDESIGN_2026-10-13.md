# PAUL PHONICS 학생용 모바일 화면 재설계 — 화면 구조와 변경 범위 (2026-10-13)

_대상: 테스터 전용 학생 화면(대시보드의 "그림 단어 연습 (테스트)" 안쪽). 기준 화면 390×844. 이 문서는 무엇을 바꾸고 무엇을 그대로 두는지 먼저 정리한 것이다._

## 1. 지금 화면의 문제 (실측)

- 첫 화면에 버튼이 30개다(레벨 3, 모드 3, 파닉스, 가게 구경, 묶음 10개 × 2, 나가기). 가게 묶음 10개가 세로로 이어져 스크롤이 길다.
- 버튼 색이 보라(`bg-purple-600`)와 하늘(`bg-sky-100`) 두 가지뿐이라 무엇이 중요한지 구분되지 않는다.
- 첫 화면에 그림이 한 장도 없다.
- Unit 허브(Book 1)는 8줄이 3묶음으로 세로로 쌓여 390px에서 화면 3개 분량이다.

## 2. 새 화면 구조

```
첫 화면 (스크롤 없음)
 ├─ 파닉스 모험  → 책장(5권) → Book(Unit 목록) → Unit
 │                    Unit: ① 듣기 → ② 따라 말하기 → ③ 게임 → ④ 복습
 ├─ 말하기       → 단계 고르기 + 단어 묶음(음식·학용품 등) → 한 장씩 카드
 └─ 게임 놀이터  → 알파벳 망치 · 숨은 글자 · 가게 구경
```

| 화면 | 바뀌는 것 | 그대로인 것 |
|---|---|---|
| 첫 화면 | 큰 그림 타일 3개 + 소리 조절 + 나가기. 버튼 30 → 5 | 소리 조절, 나가기 |
| 말하기 | 새 하위 화면. 단계(Phonics/Conversation) 선택과 묶음 10개가 여기로 이동. 묶음은 그림이 있는 2열 카드, 버튼 문구 "연습" "시험" | 묶음 구성, 단어, 연습·시험 진행 |
| 게임 놀이터 | 새 하위 화면. 알파벳 망치·숨은 글자·가게 구경 3개 타일 | 게임 내용 |
| 책장·Book | 문구를 짧게, Unit 줄을 크게 | 5권·43 Unit 구성, 임시 표시 |
| Unit 허브 | 4묶음(듣기·따라 말하기·게임·복습), 줄 높이를 줄이고 "지금 할 것" 하나만 크게 | 단계 수와 잠금 규칙, 각 단계가 여는 화면 |
| 학습 카드 | 버튼 색을 역할별로(듣기 하늘, 말하기 코랄, 다음 민트) | 한 장씩 넘기는 흐름, 녹음·재생 |

## 3. 색 역할

| 색 | 역할 | 쓰는 곳 |
|---|---|---|
| 민트 | 앞으로 가기(시작·다음), 파닉스 모험 | 주 버튼, 파닉스 타일 |
| 코랄핑크 | 말하기·녹음 | 따라 말하기, 말하기 타일 |
| 따뜻한 노랑 | 게임 | 게임 타일, 게임 묶음 |
| 라벤더 | 복습·시험 | 복습 묶음, 시험 버튼 |
| 하늘 | 듣기 | 발음 듣기, 듣기 묶음 |
| 회색 | 나가기·뒤로 | 보조 버튼 |

한 화면에서 진한 색 버튼은 하나만 쓴다(지금 할 행동). 나머지는 같은 색의 옅은 배경이다.

## 4. 그림

- 새 그림을 만드는 도구가 없다. 이미 있는 그림 단어 그림(151장, 같은 화풍)을 메뉴 그림으로 쓴다: 파닉스 모험 = 책, 게임 놀이터 = 로봇, 말하기 = 그림 카드 + 마이크 표시, 묶음 카드 = 그 묶음의 첫 그림.
- "말하기"에 딱 맞는 그림(말하는 아이, 마이크)은 없다. 전용 그림이 필요하면 제작 목록에 올려야 한다.
- 이 그림들은 교사 승인 기록이 없는 자동 연결 그림이다(이미 학생 화면에 쓰이는 119장 안에서만 고른다).

## 6. 제약과 위험

- **번들 예산**: JS 합계 2.179 / 2.2 MB, 여유 약 21 KB. 새 화면은 기존 코드와 그림을 재사용해 이 안에서 만든다.
- **검사 갱신**: 첫 화면에서 묶음·게임을 바로 누르던 브라우저 검사는 하위 화면으로 한 번 더 들어가야 한다. 검사 3종(558 단언)을 한 번에 하나씩 다시 돌린다(16 GB RAM).
- **대상**: 테스터 4명에게만 보이는 화면이다. 일반 학생은 이 청크를 받지 않는다.
